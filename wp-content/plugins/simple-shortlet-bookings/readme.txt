Lightweight booking system for shortlets (apartments, rooms).

== Description ==

Simple Shortlet Bookings is a lightweight WordPress plugin for managing shortlet bookings. Perfect for small-scale property rentals.

== Features ==

* Custom post types for shortlets and bookings
* Beautiful booking form with date picker
* Image carousels for property galleries
* Interactive maps with location display
* Email notifications for admin and guests
* Booking calendar view
* Responsive design

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/simple-shortlet-bookings` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Shortlets' in the admin menu to add your properties
4. Use the [shortlet_list] shortcode to display listings
5. Booking forms appear automatically on single shortlet pages
